# 申请反欺诈树模型与集成

复现决策树、随机森林、AdaBoost、XGBoost、LightGBM，比较测试ROC、PR与KS。

决策树：训练集4折roc_auc最佳值0.6580；参数{'class_weight': None, 'max_depth': 2, 'min_samples_leaf': 2}。

随机森林：训练集4折roc_auc最佳值0.6508；参数{'max_depth': 8, 'max_features': 0.5, 'min_samples_leaf': 2}。

AdaBoost：训练集4折roc_auc最佳值0.6563；参数{'learning_rate': 1, 'n_estimators': 15}。

XGBoost：训练集4折roc_auc最佳值0.6509；参数{'learning_rate': 0.1, 'max_depth': 3, 'n_estimators': 50}。

LightGBM：训练集4折roc_auc最佳值0.6527；参数{'learning_rate': 0.08, 'n_estimators': 100, 'num_leaves': 7}。

共27321条，正类71条；分层60/40拆分以保留少数类。CV只用训练集，统一ROC-AUC作搜索目标，阈值固定0.5，结合AP和召回率理解极度不平衡。

为可重复运行，将教材大规模网格收敛到代码列出的候选组合，所有算法均实际拟合；不冒称教材全网格最优结果。
