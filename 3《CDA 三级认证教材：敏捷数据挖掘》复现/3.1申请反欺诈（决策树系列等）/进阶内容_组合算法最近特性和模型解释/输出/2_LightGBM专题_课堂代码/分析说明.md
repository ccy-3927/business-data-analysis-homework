# LightGBM基础与约束

复现直方图梯度提升、LightGBM原生接口、类别特征、早停与约束。

真实数据39173条；训练27421条、测试11752条。缺失值和类别编码只在训练数据拟合，测试集不参与调参。

早停最佳轮次25。HistGradientBoosting是独立算法，不称为LightGBM的完全实现。

原教材对任意类别编码加单调约束，本例改在age数值列展示约束接口；此约束仅教学，不作业务断言。省去无分析作用的二进制数据副本，保留可用模型。
