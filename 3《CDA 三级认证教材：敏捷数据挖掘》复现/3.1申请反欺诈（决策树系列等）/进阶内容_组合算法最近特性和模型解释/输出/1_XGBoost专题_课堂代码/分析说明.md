# XGBoost基础与约束

复现sklearn/原生接口、早停、单调约束、交互约束及并行树。

真实数据39173条；训练27421条、测试11752条。缺失值和类别编码只在训练数据拟合，测试集不参与调参。

早停最佳轮次9；预测显式限定最佳迭代区间。

原生模型明确设binary:logistic，避免默认回归目标被误当二分类概率。前3列的单调方向和交互分组沿教材仅作接口示例，不宣称这些保险变量有真实单调因果关系。
