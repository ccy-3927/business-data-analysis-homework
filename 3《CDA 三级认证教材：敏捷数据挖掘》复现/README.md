# CDA三级：敏捷数据挖掘 Python复现

保留教材原目录，29个Notebook分别对应同名.py。各脚本的结果在同级`输出/脚本名`中。共72张静态PNG、15张交互HTML，每张图只保留一种格式；HTML需与仓库根目录`assets`一起保留，可离线打开。没有生成审阅网页。

## 运行

在本目录的PowerShell中运行：

```powershell
.venv\Scripts\python.exe 运行全部.py
```

也可只运行一个案例，例如：

```powershell
.venv\Scripts\python.exe 运行全部.py "2.1线性回归"
```

新增依赖安装在本目录的D盘`.venv`中，下载缓存也位于D盘；环境继承已有基础库。迁移到其他电脑时，可用`python -m venv .venv`建环境，再用`.venv\Scripts\python.exe -m pip install -r requirements.txt`安装。

默认读取同级教材资料中的`3《CDA 三级认证教材：敏捷数据挖掘》`。更换教材位置可设置环境变量`CDA3_SOURCE`。脚本会读取原始CSV、XES、LP及对应Notebook，勿只复制单个.py；根目录共用模块也需保留。

## 必要的复现差异

- 只用教材数据和明确给出的模型参数。教材`ts_simu200.csv`本身是模拟教学数据，已注明，未重新造数。跳过make_blobs、SMOTE/SMOTENC及DiCE合成记录；第7章使用教材真实银行数据演示不造记录的方法。
- fa_kit迁移为PCA加正交varimax；序列模式以精确子序列枚举实现并逐客户核对；CPLEX迁移为SciPy HiGHS/SLSQP；pm4py案例用XML和NetworkX实现相同的直接跟随计算。
- LSTM是显式NumPy双层LSTM，包含BPTT、Dropout和Adam，使用真实训练窗口核对数值梯度。结构沿教材，初始化和梯度裁剪有差异；没有用普通回归模型替代LSTM。
- 调参和预处理只在训练数据内完成，测试集不参与选参数。部分大型搜索采用代码所列的有限候选，LOF使用固定抽取的2万条真实训练记录与完整独立测试集；具体范围见案例分析说明，不冒称教材全网格或全量拟合结果。
- 修正分类指标正类混用、关联规则分母、LSTM预测目标错列、SARIMA预测日期重复等问题。保留必要的原口径对照或改动说明，不保证与教材旧版本输出逐数字相同。
