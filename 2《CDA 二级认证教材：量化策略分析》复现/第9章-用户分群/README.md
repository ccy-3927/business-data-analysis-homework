# 第9章-用户分群

## Kmeans 的应用 - 用户细分

脚本：`k-means聚类\Kmeans 的应用 - 用户细分.py`

四项行为标准化、三分量旋转、分位变换前后K-means、群体画像和解释树。剔除ID/总次数作为解释树输入，固定初始化种子。

## hc_city10

脚本：`层次聚类\hc_city10.py`

重算标准化与旋转得分并和保存检查点对照；按教材fa_cities_10.csv的得分复现Ward树状图和距离表。

## 使用

运行对应.py，或在“平时作业2”目录运行 `.venv\Scripts\python.exe 运行全部.py`。脚本按自身位置定位教材，不要求从章节目录启动。环境变量CDA2_SOURCE可指定二级教材根目录。

输出位于脚本同级“输出/脚本名”，含CSV、分析说明、来源哈希。静态图仅PNG，交互图仅HTML；HTML需保留同目录plotly.min.js。原代码及单元格编号见同名“原单元格对照.md”。
