## 运行

本机在此目录使用：

```powershell
.venv\Scripts\python.exe 运行全部.py
```

迁移到其他电脑可建立新环境后安装依赖：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe 运行全部.py
```

本机.venv为隔离statsmodels兼容版本而建立，继承了现有基础库；其他电脑按requirements.txt重新安装即可。不要上传或复制.venv。默认教材在同级CDA 教材资料2025/2《CDA 二级认证教材：量化策略分析》；可设置CDA2_SOURCE覆盖。
