# 第8章-使用统计学方法进行检验和预测

## 方差分析

脚本：`假设检验与方差分析\方差分析.py`

教育单因素、教育+性别加性、交互项的OLS/ANOVA及诊断。教材把空格当0的结果独立对照，主分析不把缺失当零。

## 列联表分析

脚本：`列联表检验\列联表分析.py`

破产标识与坏账频数、行比例、连续性校正/未校正卡方、期望频数及效应量；明确排除缺失数量。

## 线性回归

脚本：`线性回归\线性回归.py`

清洗、相关分析、五种回归规格、VIF、残差与Q-Q图。缺失目标不参与主模型，教材均值填补口径单独输出；年龄999按值识别，不按行号。

## 逻辑回归

脚本：`逻辑回归\逻辑回归.py`

保留教材训练测试抽样及原公式不收敛诊断；后续评估删除近乎重合的avgplan变量，修正正类指标含义；前向AIC、分类筛查和阈值选择均在训练集，测试集只评价。

## 使用

运行对应.py，或在“平时作业2”目录运行 `.venv\Scripts\python.exe 运行全部.py`。脚本按自身位置定位教材，不要求从章节目录启动。环境变量CDA2_SOURCE可指定二级教材根目录。

输出位于脚本同级“输出/脚本名”，含CSV、分析说明、来源哈希。静态图仅PNG，交互图仅HTML；HTML需保留同目录plotly.min.js。原代码及单元格编号见同名“原单元格对照.md”。
