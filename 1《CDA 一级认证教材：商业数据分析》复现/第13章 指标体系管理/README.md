# 第13章 指标体系管理

已复现模板中的真实汇总表，并迁移标准定义。

基础模板包含2011条标准的主题×部门汇总，复现分布图并核对全部行列总计。客户标准示例、指标定义、维度和代码导出CSV。

只有汇总，没有2011条明细，不能反推明细。指标SQL含占位表名字段，不能计算实际银行余额、不良率。PDF规范和维度树示意不硬做数据项目。

## 文件与运行

- `01_数据标准模板迁移.py`

在“平时作业”目录执行：

```powershell
python "第13章 指标体系管理/运行本章.py"
```

依赖在父目录 requirements.txt；教材默认从同级原目录读取，也可用环境变量 CDA_SOURCE 指定教材根目录。

输出目录按脚本分组，包含计算CSV、静态PNG或交互HTML（每张图仅一种格式）、数据来源SHA256和分析说明。交互HTML为独立图，需与同目录plotly.min.js一起保留，离线打开可查看。没有审阅页面。
