# 第10章 使用效应分解方法做预报

航空及信用卡时间序列案例已迁移。

航空采用对数季节分解与Holt-Winters预测，末12个月留出回测，另输出24个月预测。信用卡两份数据独立拟合趋势与星期效应，并留出7日回测。

WPS已保存预测仅作参考，未混进训练集。Python方法与Power BI/WPS并非数值完全一致，未伪造其置信区间。所有预测明确标为模型输出。

## 文件与运行

- `01_效应分解与预测.py`

在“平时作业”目录执行：

```powershell
python "第10章 使用效应分解方法做预报/运行本章.py"
```

依赖在父目录 requirements.txt；教材默认从同级原目录读取，也可用环境变量 CDA_SOURCE 指定教材根目录。

输出目录按脚本分组，包含计算CSV、静态PNG或交互HTML（每张图仅一种格式）、数据来源SHA256和分析说明。交互HTML为独立图，需与同目录plotly.min.js一起保留，离线打开可查看。没有审阅页面。
