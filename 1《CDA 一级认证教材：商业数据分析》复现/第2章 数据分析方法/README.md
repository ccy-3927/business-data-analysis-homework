## 运行

在 `平时作业` 目录执行：

```powershell
python -m pip install -r requirements.txt
python "第2章 数据分析方法/运行第二章.py"
```

也可单独运行各脚本。输出位于 `输出/脚本名/`，基础范式下再分6个案例。`chapter2.py` 是本章辅助模块，`../common.py` 为两章共用模块。源数据默认位于同级教材目录，或设置环境变量 `CDA_SOURCE` 指向一级教材目录。全章运行成功会更新 `运行结果.json`。

## 图表来源与边界

- 按原案例重算：模型分层、同期群、漏斗、相关和销售指标。不是直接复制答案，参考表只用于核对。
- 展示调整：部分饼图/地图/卡片改为条形图或数值表；订单量和环比分开呈现。保留分析口径，不声称原界面像素复刻。
- 补充图：部门人数、成绩分布、模型区域销售及部分经营趋势用于表达 Python 结果，不能宣称每张都是教材原图。
- 独立交互：双击 `_交互.html`，可悬停、点击图例、缩放、导出。桑基可拖节点，服装店铺图可切月份。同目录 `plotly.min.js` 必须一起保留，离线使用，不是审阅页面。
- 不硬复现：第三方插件安装包、重复版本、空白表、视频鼠标操作，以及只有概念/函数清单而无具体任务的段落。ToS 重复数据不重复统计。未发现本章 ipynb。

## 重要计算口径

1. 部分 Excel 输入来自 RAND/RANDBETWEEN，代码只读已保存缓存，不执行随机函数。每个案例保存源文件路径和 SHA256；重算原表可能使输入值改变。
2. RFM 使用教材时点及去重流水号；R小于均值为高，F/M大于均值为高。忠诚度先分出潜在/易流失用户，再计算其余用户四分位阈值。
3. 同期群按用户去重；未来未到观察期留空。注册全集缺失与购买历史左截断限制写在各案例说明中。
4. 服装指标以明细为度量源，订单只提供维度。折扣率、客单价、连带率用汇总后的分子分母计算。无目标的期间留空，不补目标。
5. 数据清洗只处理可确定的空格、类型和键名。金额缺失不填0；源表错误编码单列，不伪造商品键。计费和工作日规则只使用原表规定。
6. 箱体为Q1/Q3、中线中位数、须为1.5IQR内最远观察值，须外点保留。相关拟合为样本内描述，不能解释为因果或已验证预测。

每个案例有 `分析说明.md`、`数据来源.json` 和 CSV，部分另有参考差异表及关联校验。`输出/教材材料与实现对应清单.csv` 说明材料对应的脚本、合并与跳过原因。

原始教材不随代码复制。服装材料的使用/发布说明保留供最终授权发布时核对；当前仅本地完成作业。
