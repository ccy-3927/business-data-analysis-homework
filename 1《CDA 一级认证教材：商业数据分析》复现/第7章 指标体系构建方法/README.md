# 第7章 指标体系构建方法

指标字典已迁移；无可计算的业务观测数据。

Step2已填写12项指标，导出CSV/JSON并核对关联指标名称。Step1为空白设计框架。课件中的流程图和示意数字不扩造成业务样本，不画虚构漏斗。

## 文件与运行

- `01_指标字典迁移.py`

在“平时作业”目录执行：

```powershell
python "第7章 指标体系构建方法/运行本章.py"
```

依赖在父目录 requirements.txt；教材默认从同级原目录读取，也可用环境变量 CDA_SOURCE 指定教材根目录。

输出目录按脚本分组，包含计算CSV、静态PNG或交互HTML（每张图仅一种格式）、数据来源SHA256和分析说明。交互HTML为独立图，需与同目录plotly.min.js一起保留，离线打开可查看。没有审阅页面。
