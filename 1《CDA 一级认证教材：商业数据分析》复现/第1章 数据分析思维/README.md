## 运行

在 `平时作业` 目录执行：

```powershell
python -m pip install -r requirements.txt
python "第1章 数据分析思维/运行第一章.py"
```

商场默认选择 2019 年，可单独切换年月：

```powershell
python "第1章 数据分析思维/03_维度模型商场案例.py" --year 2018 --month 10
```

不同年月图表用不同文件名保留，分析说明记录最后一次筛选条件。恢复默认2019年结果请重新运行总入口。所有脚本使用相对项目位置寻址，不依赖启动工作目录。

## 数据来源与可迁移性

默认数据路径为 `平时作业` 的同级目录 `CDA 教材资料2025/1《CDA 一级认证教材：商业数据分析》`。另一台电脑可以保留此结构，或设置 `CDA_SOURCE` 为该教材目录的绝对路径。原始数据仅被读取；输出中的 `数据来源.json` 记录相对路径及 SHA256。未复制教材大文件到作业中。

静态图仅提供 PNG，交互图仅提供 HTML，同一图不重复输出，计算表使用 UTF-8 BOM CSV，可用 Excel 打开。`common.py` 是共用读取与作图模块，需要与章节目录一起保留。中文字体优先使用 Windows 微软雅黑或黑体，其他系统运行需要安装相应中文字体。

## 必须理解的分析口径

1. 维度决定如何分组，指标决定对什么字段采用什么汇总方式。利润率应以汇总利润除以汇总销售额。
2. 卡通过 `disp_id` 关联到客户，贷款通过 `account_id` 关联账户所有者；不能把一个账户的所有授权人都当作借款人，否则贷款额会膨胀。
3. 商场事实表产品编码为小写，产品维表为大写；规范编码后建立多对一连接，并检查行数和金额守恒。
4. 商场第2页实际计算是记录平均销售额，虽然 PBIX 字段别名含有 `Sum`。实现依据计算定义，不按字段别名猜测。
5. 商场源表 4 条记录金额不满足“数量×单价”，差异合计 48,020 元；保留原销售额以匹配教材，不推测折扣或擅自修正。详见差异清单。没有交易唯一标识，因此不机械删除完全相同记录。
