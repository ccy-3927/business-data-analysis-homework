# 第9章 用户标签体系与用户画像专题

信用卡取数和定量画像已迁移。

基于教材SQL与课件，输出发卡趋势、卡类型、性别、年龄、历史交易和余额画像；分别实现180天与365天窗口。

严格排除发卡当日及之后流水。同日最后多笔余额按第二套SQL取均值。借贷金额保留中性名称；不凭数据臆造姓名、爱好、婚姻状态或用户评分。参考报告和标签规范不当作客户观测样本。

## 文件与运行

- `01_信用卡客户画像.py`

在“平时作业”目录执行：

```powershell
python "第9章 用户标签体系与用户画像专题/运行本章.py"
```

依赖在父目录 requirements.txt；教材默认从同级原目录读取，也可用环境变量 CDA_SOURCE 指定教材根目录。

输出目录按脚本分组，包含计算CSV、静态PNG或交互HTML（每张图仅一种格式）、数据来源SHA256和分析说明。交互HTML为独立图，需与同目录plotly.min.js一起保留，离线打开可查看。没有审阅页面。
