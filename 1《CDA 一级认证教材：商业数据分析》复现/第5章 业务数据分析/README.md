# 第5章 业务数据分析

两个银行实操均已迁移。

理财销售完成目标进度、品类与风险偏好、客群下钻、购买动机分析；贷款申请完成月度趋势、渠道构成、5月增减归因。

分解树迁移为独立交互矩形树图；词云改为可比较的频数图。A/B实验只有设计没有观测数据，不生成实验结果。

## 文件与运行

- `01_银行理财销售分析.py`
- `02_贷款申请渠道归因.py`

在“平时作业”目录执行：

```powershell
python "第5章 业务数据分析/运行本章.py"
```

依赖在父目录 requirements.txt；教材默认从同级原目录读取，也可用环境变量 CDA_SOURCE 指定教材根目录。

输出目录按脚本分组，包含计算CSV、静态PNG或交互HTML（每张图仅一种格式）、数据来源SHA256和分析说明。交互HTML为独立图，需与同目录plotly.min.js一起保留，离线打开可查看。没有审阅页面。
