# 第3章 商业数据分析框架

三个案例均已迁移。

收入分析按年度、月份、11月省份、四川逐层下钻；费用案例分别计算原始版和完整版，导出对账差异；精准营销按性别、年龄、品类和支付方式筛选。

教材同比公式分母及女性年龄表有问题，代码采用明确口径并保留差异。费用两版数据不混用。

## 文件与运行

- `01_收入趋势与异常下钻.py`
- `02_期间费用归因.py`
- `03_电商精准营销.py`

在“平时作业”目录执行：

```powershell
python "第3章 商业数据分析框架/运行本章.py"
```

依赖在父目录 requirements.txt；教材默认从同级原目录读取，也可用环境变量 CDA_SOURCE 指定教材根目录。

输出目录按脚本分组，包含计算CSV、静态PNG或交互HTML（每张图仅一种格式）、数据来源SHA256和分析说明。交互HTML为独立图，需与同目录plotly.min.js一起保留，离线打开可查看。没有审阅页面。
