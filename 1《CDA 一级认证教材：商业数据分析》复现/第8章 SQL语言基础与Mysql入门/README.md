# 第8章 SQL语言基础与Mysql入门

SQL基础案例已迁移为Python。

覆盖去重、筛选、排序、表达式、CASE、汇总、连接、子查询、集合操作和视图；按建表SQL读取无表头CSV。

贷款前一年用真实日期差实现；视图及简单聚合用内存SQLite辅助核对。没有安装或连接MySQL，安装视频和环境说明不作为复现图。开窗函数PDF为补充语法参考，未自造数据题。

## 文件与运行

- `01_SQL案例迁移.py`

在“平时作业”目录执行：

```powershell
python "第8章 SQL语言基础与Mysql入门/运行本章.py"
```

依赖在父目录 requirements.txt；教材默认从同级原目录读取，也可用环境变量 CDA_SOURCE 指定教材根目录。

输出目录按脚本分组，包含计算CSV、静态PNG或交互HTML（每张图仅一种格式）、数据来源SHA256和分析说明。交互HTML为独立图，需与同目录plotly.min.js一起保留，离线打开可查看。没有审阅页面。
