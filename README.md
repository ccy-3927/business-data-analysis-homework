# 商业数据分析平时作业

四本教材的Python案例复现，按教材章节保留代码、图表、主要计算结果与简短分析说明。

## 内容

- **CDA一级：商业数据分析**：业务分析、指标、SQL迁移、客户画像与预测。
- **CDA二级：量化策略分析**：数据处理、可视化、统计检验、回归与聚类。
- **CDA三级：敏捷数据挖掘**：机器学习、关联规则、时间序列、优化、流程挖掘。
- **金融数据分析和数据挖掘案例实战**：精准营销、A/B评分卡、Vintage、反欺诈与社交网络。

## 查看与运行

进入各教材目录，先看README，再查看章节中的Python脚本和`输出`目录。静态图使用PNG；交互HTML请下载仓库后在浏览器打开，GitHub文件预览不执行交互脚本。共享JS位于`assets`，请与HTML一起保留。

原始教材和配套输入数据不随仓库上传。代码运行仍需本地教材CSV、Excel、Notebook等文件；不要将输出CSV当作原始输入。默认目录布局：

```text
同一父目录/
├── business-data-analysis-homework/
└── CDA 教材资料2025/
    ├── 1《CDA 一级认证教材：商业数据分析》/
    ├── 2《CDA 二级认证教材：量化策略分析》/
    ├── 3《CDA 三级认证教材：敏捷数据挖掘》/
    └── 4《金融数据分析和数据挖掘案例实战》/
```

也可分别设置`CDA_SOURCE`、`CDA2_SOURCE`、`CDA3_SOURCE`、`CDA4_SOURCE`到对应教材目录。在每本教材复现目录安装其`requirements.txt`依赖后，按该目录README运行。

### 客户画像：从单一标签到交叉客群

对教材中的 **167,177 条客户记录**进行清洗、分位变换和因子旋转，再分别构建家庭与爱好画像。保留教材的家庭 3 群、爱好 2 群，将两类标签交叉，形成六类客群。

| 家庭群 | 爱好群 0 | 爱好群 1 | 合计 |
| :--- | ---: | ---: | ---: |
| 0 | 49,761 | 27,713 | 77,474 |
| 1 | 7,068 | 10,460 | 17,528 |
| 2 | 26,325 | 45,850 | 72,175 |
| **合计** | **83,154** | **84,023** | **167,177** |

交叉结果能进一步区分同一家庭群内的兴趣差异。例如，家庭群 0 中爱好群 0 的人数更多，而家庭群 2 中爱好群 1 的人数更多，可作为分层运营的分析起点。群编号只是聚类标签，具体含义需要结合原指标均值解释，不能直接视为客户价值排序。

### Vintage 分析：比较不同放款批次的风险

从教材 SQL 记录计算不同放款批次在各账龄的逾期本金率。将贷款按放款批次分组，并对齐账龄，可以观察各批次在相同存续阶段的风险表现。

| 分析要素 | 本案例的处理方式 |
| :--- | :--- |
| 分组维度 | 按放款批次划分贷款群体 |
| 时间维度 | 以账龄比较贷款发放后的表现 |
| 风险指标 | 逾期贷款剩余本金 ÷ 该批次原始放款金额 |
| 阅读重点 | 同一账龄比较不同批次；沿同一批次观察风险随账龄的变化 |

### 运筹优化：找到约束条件下的最优生产方案

将教材的生产规划从 CPLEX 迁移到 Python 的 SciPy HiGHS 求解器，直接读取 `productivity.lp` 中的目标函数与约束，求解资源限制下的最优生产组合。

| 结果项 | 求解结果 | 含义 |
| :--- | ---: | :--- |
| 决策变量 x1 | 50 | 第一类产品的最优生产数量 |
| 决策变量 x2 | 250 | 第二类产品的最优生产数量 |
| 最大目标值 | 27,500 | 上述生产组合对应的目标函数值 |

本案例采用教材实际读取的两变量生产模型。求解后检查生产数量是否满足资源约束，将“最优解”落实为可执行的生产组合。
